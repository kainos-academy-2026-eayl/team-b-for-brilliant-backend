Lesson 01 / 15 minutes / Docker foundations

Recipe, package, process.

Explain what we built before learning how we made it smaller.

Your win: identify a Dockerfile, image, and container in this backend, then run one safe command that makes the distinction visible.

1. Three different things (4 min)

A Dockerfile is a text file, not a server. An image packages application files, Node.js, libraries, and startup configuration. A running container executes a process using that image, with its own writable layer and runtime settings. A stopped container is still a container.

Primary sources: Dockerfile, image, container.

In our project, FROM node:22-alpine AS base chooses a starting image. The final CMD ["node", "dist/index.js"] records the default startup command; it does not start the backend while the image is being built.

An image does not change just because you edit the Dockerfile. You must build again. Existing containers do not automatically switch to the new image. Why rebuilding matters.

2. Predict, then observe (4 min)

In the backend repository terminal, run this read-only inspection:

docker image inspect lukealderdice09647/backend:v1.00.01-alpine --format '{{.Id}}'

You should see an image ID beginning with sha256:. If Docker cannot find it, stop and ask me; do not rebuild or delete anything for this lesson.

Predict first: will the next command rebuild the image, start our HTTP server, or run a short Node process?

docker run --rm lukealderdice09647/backend:v1.00.01-alpine node --version
After running it: compare with the expected result

It prints a Node 22 version, then exits. Docker creates a container using the existing image. node --version overrides our default startup command, so no backend server or database is started. --rm removes this temporary container when it exits; it does not delete the image. Container lifecycle source.

Our two tagged backend images are packages you can reuse. Building them did not leave the backend server running. The existing Compose file starts Postgres, not the backend. Those are different operations.
